# Robotics, Vision & Communication Integration

An integrated robotics demonstration combining autonomous mobile robots, 3D vision, industrial robot arms, and pneumatic grippers.

## Project Overview

At INA Oriental Motor, I integrated existing robotic and vision systems into a coordinated demonstration workflow. The setup connected MiR autonomous mobile robots, Solomon 3D vision, Doosan robot arms, and Schunk pneumatic grippers. My work focused on system integration, device communication, control coordination, and on-site setup for the exhibition.

## System Components

- **Autonomous mobile robots:** MiR
- **3D vision:** Solomon
- **Robot arms:** Two Doosan robots
- **End effectors:** Two Schunk pneumatic grippers

## My Contribution

- Integrated independently controlled robotics and vision equipment into one demonstration system.
- Coordinated communication and control across the mobile robots, vision system, robot arms, and grippers.
- Organized and verified system cabling and connections during installation.
- Supported the final setup and operational readiness for the exhibition.
