## System Configuration

| **Component** | **Configuration** |
|---|---|
| Autonomous mobile robot | [MiR AMR](https://mobile-industrial-robots.com/) |
| 3D vision system | [Solomon 3D Vision](https://www.solomon-3d.com/) |
| Industrial robot arms | [Two Doosan 6-axis collaborative robots](https://www.doosanrobotics.com/en) |
| Grippers | [Two Schunk pneumatic grippers](https://schunk.com/us/en/products/current-highlights/pneumatic-gripping) |

**Additional integration:** Connected a separate 6-axis robot (model undisclosed) with an external LMS device.

## Communication and Wiring

- **Relay:** Wired the robot, pneumatic grippers, pneumatic equipment, Bluetooth box, and digital I/O connections.
- **Bluetooth box (digital I/O):** Connected the MiR AMR and robot system.
- **REST API:** Connected external web clients, such as smartphones, to the system.


## My Role

I brought independently controlled robotics and vision equipment together into a coordinated demonstration workflow. I worked on system-wide integration and communication, coordinated equipment operation, and prepared and verified the physical connections for the exhibition.

- Integrated the mobile robot, vision system, robot arms, and grippers into one demonstration setup.
- Coordinated communication and control across the connected equipment.
- Organized and checked system cabling during installation.
- Supported final system setup and operational readiness for the exhibition.

Robotics, Vision & Communication Integration

I integrated a robotics demonstration system combining a MiR autonomous mobile robot, Solomon 3D vision, two Doosan 6-axis collaborative robots, and Schunk pneumatic grippers. My contributions included proposing the PCB assembly demonstration, independently implementing its Doosan robot control, and integrating the equipment and communication interfaces for the exhibition.

My Contributions

Proposed the PCB assembly concept for the Doosan robot demonstration.

Independently developed and implemented the robot control sequence for the PCB assembly demonstration. I was the only person on the project team who completed this control implementation.

Integrated the MiR AMR, Solomon 3D vision, Doosan robots, pneumatic grippers, and external LMS equipment into coordinated demonstrations.

Connected the MiR and robot system through a Bluetooth box using digital I/O.

Used relays to connect robot, gripper, pneumatic, Bluetooth box, and digital I/O circuits.

Connected external web clients, including smartphones, through a REST API.

Prepared and verified system wiring and supported exhibition setup.
